# 📃 Описание проекта

Получены данные эксперимента по выращиванию водорослей из [репозитория с данными НАСА](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/). В рамках проекта было создано несколько моделей для предсказания завтрашней плотности водорослей на основе сегодняшних признаков.

## 📦 Описание данных

Данные по ссылке представляют собой zip-архив, внутри которого содержится файл с данными в формате mat и файла с описанием эксперимента и его данных в формате pdf. Описание данных далее взято из указанного файла Readme.

Данные организованы в MATLAB-файле в виде структурного массива размером 1×3 с полями:

- irradiance (освещённость)
- temperature (температура)
- pH (кислотность)
- oxygen (кислород)
- DIC (растворённый неорганический углерод)
- nitrate (нитраты)
- phosphate (фосфаты)
- chlorophyll_a (хлорофилл a)
- density (плотность)
- salinity (солёность)
- PAM0
- PAM8
- PAM16
- comments (примечания)

Каждый структурный массив соответствует отдельной гоночной трассе (каналу).

Каждая из переменных (irradiance, pH и т.д.) содержит записи **data** (данные) и **(нормализованное) время**, например:

`algae(1).pH.data: [48×1 double]`  
`algae(1).pH.time_num: [48×1 double]`

где:
- **`data`** — содержит сырые (исходные) измерения;
- **`time_num`** — время, приведённое к началу экспериментов (отсчитывается от 02.02.2010) в единицах **суток**.

## 🏆 Выводы

На анализ получен mat-файл с параметрами трех экспериментальных дорожек. К нему прилагался Readme-файл с описанием эксперимента и его данных.

На основе mat-файла были получены csv-файл с данными по каждой из трех эксперементальных дорожек, на которых потом после отбора признаков обучены модели LGBM (потенциально лучше учитывали характер данных).

Лучшей моделью (по балансу метрик и сложности) была признана модель 5 (модель LGBM с некоторыми добавленными лаговыми признаками). Ее метрики:

Модель  |   CV MAE  | Full MAE |  R²    |
--------|-----------|----------|--------|
lgbm_5  |   0.3162  |  0.1323  |  0.8749|

При этом диапазон значений признака density (являющегося исходным для целевого признака) составляет от 0.001187 до 2.240058. То есть можно сказать, что модель хорошего качества (особенно - с учетом проблемности данных).

Увеличить количество используемых данных не представляется возможным. Возможно, введение еще большего количества дополнительных признаков на основе имеющихся могло бы улучшить метрик модели, но это усложняет бы модель и увеличивает риск переобучения (то есть в итоге ухудшить качество).

# 🛠 Инструменты
`python`, `pandas`,  `numpy`, визуализация данных с помощью  `matplotlib`, `missingno` и `seaborn`, модель `LGBM`, метрика из `sklearn`, перебор гиперпараметров в целях определения лучшей модели с помощью `Optuna`, замер времени с помощью `time`, библиотека для работы с файлами, дисковым пространством`os`.
